## About the Tutorial

CSS stands for Cascading Style Sheets. It tells the browser how an HTML page looks: colour, type, spacing, and layout.

This tutorial explains the CSS used in the browser, with a short overview of each topic and a practical example. The pages are the Acme HR portal from the HTML tutorial. An office in Hyderabad. Amounts are in ₹.

## Audience

This tutorial is for aspiring web designers and developers who can write an HTML page and need to style it.

## Prerequisites

Before proceeding you should be able to:

- Write an HTML document with `lang`, charset, viewport, and a title.
- Save files in one folder and open them in a browser.
- Read a simple Acme HR page: a header, a directory, and a leave form.
