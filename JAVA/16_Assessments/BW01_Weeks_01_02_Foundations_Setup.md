1. A computer mainly follows which pattern?
   a) Input → Process → Output

   b) `.exe`

   b) `HelloJava.class` bytecode

   a) `2marks`

   a) `2.5`

   a) Returns `78`
   b) Returns `78.5`
   c) Throws `NumberFormatException`
   d) Returns `null`

   a) Show output on the screen

    a) `String`

    a) Web browser only
    b) Database server

    a) Any method named `start`
