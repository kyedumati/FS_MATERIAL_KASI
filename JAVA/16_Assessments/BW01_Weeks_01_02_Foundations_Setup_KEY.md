1. **a** — Input → Process → Output
2. **a** — `.java`
3. **d** — ls

5. **b** — `studentName`
6. **b** — `2` (integer division)
7. **c** — Throws `NumberFormatException`
8. **b** — percent of subtotal
9. **a** — Show output on the screen
10. **a** — `String`
11. **c** — Code editor / IDE
12. **b** — `public static void main(String[] args)`

## B. Coding — model points

1. Ask for a **Swiggy** canteen item **price** and **qty**. Compute total with **5% GST** and print `Total: ₹…` with 2 decimals. Linear `main` only.
   - Award marks for correctness + teaching-order constraints respected (`Scanner` + `parseDouble`/`parseInt`, `* 1.05` or equivalent, `printf` `%.2f`).

2. Read three subject marks with `Double.parseDouble` and print average with 2 decimals. No loops / extra methods.
   - Three reads; `(m1+m2+m3)/3.0`; no `if`.

## C. Short answer — model

Algorithm = steps in English/logic; program = those steps written in a language the computer runs (e.g. Java). Example: steps to compute GST vs a `.java` file that prints the total.
