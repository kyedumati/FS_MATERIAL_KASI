# Workspace checklist

Create under your training drive:

```text
ksr_java_fullstack/
  projects/
  notes/
  labs/
```

Commands to practise (macOS/Linux):

```bash
mkdir -p ksr_java_fullstack/{projects,notes,labs}
cd ksr_java_fullstack
pwd
ls -la
```

Windows PowerShell:

```powershell
mkdir ksr_java_fullstack\projects, ksr_java_fullstack\notes, ksr_java_fullstack\labs
cd ksr_java_fullstack
pwd
dir
```

- [ ] Three folders exist
