# Campus Canteen Calculator

CLI that totals tea and lunch bills in INR. Small Java helpers used in KSR Full Stack training.

## Tech Stack

JDK 17

## Run

```bash
javac CanteenCalculator.java
java CanteenCalculator
```

Windows (same JDK 17):

```text
javac CanteenCalculator.java
java CanteenCalculator
```
