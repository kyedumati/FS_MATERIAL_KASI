# Workspace checklist

Create under your training drive:

```text
KSR_Python/
  projects/
  notes/
  labs/
```

Commands to practise (macOS/Linux):

```bash
mkdir -p KSR_Python/{projects,notes,labs}
cd KSR_Python
pwd
ls -la
```

Windows PowerShell:

```powershell
mkdir KSR_Python\projects, KSR_Python\notes, KSR_Python\labs
cd KSR_Python
pwd
dir
```

## Done when
- [ ] Three folders exist
- [ ] Screenshot or paste of `pwd` + listing saved in `notes/day1.txt`
