# Campus Notes

Lab notebook for canteen totals and setup reminders. Used in KSR Full Stack training (Python or Java batch).

## Features

- Canteen spend notes in INR
- Ignore file for venv, target, and secrets

## Tech stack

Python 3 **or** JDK 17 — use the stack of this batch.

## Setup

```bash
git clone <url>
cd campus-notes
```

**Python FS**

```bash
python -m venv venv
source venv/bin/activate
python main.py
```

**Java FS**

```bash
javac CanteenCalculator.java
java CanteenCalculator
```
