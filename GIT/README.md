# Git and GitHub

**Shared topic pack** — used by Python Full Stack and Java Full Stack.  
Not owned by `PYTHON/` or `JAVA/`.

Git is the same skill in both batches. Teach these files once. Do not copy them into a program folder.

**Python FS schedule:** Week 9 / S44–S45 — [Session Calendar](../PYTHON/Session_Calendar_100.md)  
**Java FS schedule:** Week 9 / S44–S45 — [Session Calendar](../JAVA/Session_Calendar_100.md)

**Five sessions, about six hours.** If live time is only S44–S45, run Sessions 1–2 in class and Sessions 3–5 as extra lab. Session 5 (IDE) can always be homework.

## Not in this pack

Git internals, advanced reset, rebase, cherry-pick, reflog, detached HEAD, submodules, hooks, GitHub admin, multiple branching strategies, and long command lists.
