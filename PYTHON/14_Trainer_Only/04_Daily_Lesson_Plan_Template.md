## Default 75-minute shape (all modules)

| Minutes | Block | Do |
|--------:|-------|----|

| 35 | Lab | Learners code the kit |
| 10 | Exit | One check + homework from calendar |

Do **not** invent a multi-hour agenda. If the calendar lists several days for one file, repeat this shape with a **new focus** each day.
